# Add annotations and controls to PDF layers in C# and VB.NET

This sample shows how to associate annotations and form controls with layers in a PDF document using the [Docotic.Pdf library](https://bitmiracle.com/pdf-library/).

All widget and control classes expose a [Layer property](https://api.docotic.com/pdfwidget-layer). To associate a widget or control with a layer, simply assign the layer to this property.

To remove a widget or control from a layer, set its `Layer` property to `null`.
