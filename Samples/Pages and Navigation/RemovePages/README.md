# Remove PDF pages

This sample shows how to remove pages from PDF documents in C# and VB.NET.

The [Docotic.Pdf library](https://bitmiracle.com/pdf-library/) provides several methods for removing pages from the collection exposed by the `PdfDocument.Pages` property.

Use the `RemoveAt` method to remove an individual page by its index. To remove multiple pages at once, use the `RemoveFrom` or `RemoveRange` method.
