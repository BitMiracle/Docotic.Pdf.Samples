# Set up PDF page labels in C# and VB.NET

This sample shows how to assign custom labels to PDF pages using the [Docotic.Pdf library](https://bitmiracle.com/pdf-library/).

The [PdfDocument.PageLabels](https://api.docotic.com/pdfdocument-pagelabels) property provides access to the collection of page-labeling ranges in a PDF document. Use the `PdfPageLabels.Add` methods to define page labels for individual pages or ranges of pages.
