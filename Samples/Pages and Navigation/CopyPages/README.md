# Copy PDF pages

This sample shows how to copy pages from one PDF document to another using the [Docotic.Pdf library](https://bitmiracle.com/pdf-library/).

Use one of the `Copy` methods of the `PdfDocument.Pages` collection in your C# or VB.NET code to copy PDF pages without modifying the source document.

Call the [PdfDocument.RemoveUnusedResources](https://api.docotic.com/pdfdocument-removeunusedresources) method on the destination document to remove unused resources, such as fonts and images, that may be referenced by the copied pages.
