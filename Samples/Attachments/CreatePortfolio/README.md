# Create PDF portfolio in C# and VB.NET

This sample shows how to create a PDF portfolio using the [Docotic.Pdf library](https://bitmiracle.com/pdf-library/).

PDF portfolios allow you to combine multiple files into a single PDF document. Use the `PdfDocument.Collection` property to enable the portfolio view.

The `PdfCollectionSettings.InitialDocument` property specifies which attached document to display when the portfolio is opened in a PDF reader that supports PDF portfolios.

You can use Adobe Acrobat, Foxit Reader, or PDF-XChange Editor to view PDF portfolios.
