# Add list boxes to PDF document in C# and VB.NET

This sample shows how to add and use list boxes in PDF documents with the [Docotic.Pdf library](https://bitmiracle.com/pdf-library/).

Use the [PdfPage.AddListBox methods](https://api.docotic.com/pdfpage-addlistbox) to add a list box to a PDF page. These methods return an instance of the [PdfListBox class](https://api.docotic.com/pdflistbox).

Use the `Add` method of the `PdfListBox.Items` collection to add items to the list box.

Use the [PdfListBox.SelectItems method](https://api.docotic.com/pdflistbox-selectitems) to select one or more items in the list box.
